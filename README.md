## 🎯 Overview

**Mada Dépannage** is an on-demand service platform connecting customers with qualified service providers across Madagascar (Antananarivo, Toamasina, Mahajanga, Fianarantsoa, Antsiranana, and other provinces).

The platform addresses urgent needs including:
- Car/motorbike breakdowns 🚗
- Plumbing emergencies 💧
- Home hairstyling services ✂️
- Courier/delivery services 📦

**Key differentiators:**
- 📍 Geolocation-based provider matching
- 📡 Offline-first architecture (optimized for unstable connections)
- ⭐ Verified profiles with rating system
- 💰 Mobile Money integration (MVola, Orange Money)

## ✨ Features

### Customer Features
- ✅ Easy registration & login
- ✅ Find nearby providers in real-time
- ✅ Request services with one tap
- ✅ Track provider arrival live
- ✅ Rate and review services

- ✅ Accept/reject service requests

- ✅ Earnings dashboard
- ✅ Service history
- ✅ QR code check-in/out

- ✅ User management
- ✅ Service validation
- ✅ Transaction monitoring
- ✅ Analytics dashboard
- ✅ Push notifications

### Technical Features
- 📱 Offline mode with data synchronization
- 🗺️ Real-time GPS tracking
- 🔔 Push notifications
- 💾 Local caching (AsyncStorage + Redis)
- 🔄 Automatic retry on network failure
- 🌐 Multi-language support (French, Malagasy)
